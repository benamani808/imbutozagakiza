# Family Imbuto Z’Agakiza

Christian ministry website with an admin panel for content, photos, events, sermons, membership requests, prayer requests, messages, and donations.

## Development

```sh
bun install
bun run dev
```

## Administration

Open `/admin` to sign in. Save website edits with **Save changes**. Uploaded photos are stored in cloud storage and remain available after reloads.

Online donations use Flutterwave. Configure the public checkout key and payment details in the admin settings.
